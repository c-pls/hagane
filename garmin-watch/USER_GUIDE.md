# Hagane for Garmin — User Guide

Hagane is a strength-training app for the **Garmin Forerunner 255 / 255 Music**. You plan your routines in the Hagane phone app; the watch runs the workout and saves it to **Garmin Connect**.

---

## 1. Quick start

1. **Phone**: open the Hagane Android app and create your routines (exercises, sets, reps, weight, rest time).
2. **Watch**: press **START** → choose **Hagane** (next to Run, Bike…).
3. The watch asks your phone for the latest routines and stores them on the watch. After that it works **offline** — you can leave the phone in the locker.
4. Pick a routine with **UP / DOWN**, press **START** to begin.

> No routines showing? Open the Hagane app on the phone once (so it can answer), then on the watch **hold UP** on the routine list to sync again.

---

## 2. Buttons

| Button | Routine list | Set screen | Rest screen | Menus |
| :-- | :-- | :-- | :-- | :-- |
| **START** (top-right) | Start routine | **Finish set** | Start next set now | Select |
| **BACK** (bottom-right) | Exit app | Pause menu | Pause menu | Back / Resume |
| **UP** (middle-left) | Previous routine | **+1 rep** | **+15 s** rest | Move up |
| **DOWN** (bottom-left) | Next routine | **−1 rep** | **−15 s** rest | Move down |
| **Hold UP** | Sync from phone | Switch exercise | Switch exercise | — |

---

## 3. During a workout

### Set screen
- Top: exercise number and set (e.g. `EX 2 • SET 1/3`). Orange = warm-up, purple = superset.
- Big numbers: **weight (kg)** on the left, **reps** on the right.
- Bottom: live heart rate, how long this set has lasted, and the time of day.
- Press **START** when the set is done.

### Log what you really did
- Did 9 reps instead of 10? Press **DOWN** once. Did 11? Press **UP**.
  Changed numbers turn **orange**.
- Different weight? **BACK → Edit Weight**, change in 2.5 kg steps with UP / DOWN, press **START**.
  The new weight applies to this set and the remaining sets of the same exercise.
- Whatever is shown when you press START is what gets saved.

### Rest screen
- Countdown to the next set, with your heart-rate drop from the set's peak.
- Buzz at 10 s left, a short buzz each second for the last 3 s, and a long pattern at 00:00.
- After 00:00 the timer counts up in orange (overtime) until you press **START**.
- **UP / DOWN** add or remove 15 s. **START** skips the rest.
- Supersets (3A / 3B): no rest between the two; rest starts after the second exercise.

### Machine busy? Switch exercise
1. **Hold UP** (on the set or rest screen).
2. Pick another exercise with UP / DOWN, press **START**.
3. Do it. When it is finished, Hagane takes you **back to the exercise you left**.
   You can also use **BACK** to cancel the picker.

---

## 4. Pause menu (press BACK)

| Item | What it does |
| :-- | :-- |
| **Resume** | Continue the workout |
| **Select Exercise** | Jump to any exercise |
| **Edit Weight** | Change weight for this and later sets of the exercise |
| **Undo Set** | Go back one set to redo it |
| **Skip Set** | Skip the current set |
| **Save** | Finish and save the workout |
| **Discard** | Throw the workout away (asks to confirm) |

When every set is done the menu opens by itself with **Save** selected.
You can still choose **Resume** to add extra sets of any exercise.

---

## 5. If the app closes mid-workout

Next time you open Hagane it offers:
- **START** — resume where you stopped
- **BACK** — discard

Progress is kept on the watch only and expires after **6 hours**.
The part you did before the app closed is already saved to Garmin Connect as its own activity; the rest is saved as a second one.

---

## 6. After the workout

- A summary shows total time, sets, reps, volume and heart rate. Use UP / DOWN to see each exercise.
- The activity (heart rate, calories, set laps with exercise name, reps and weight) is saved to **Garmin Connect** on your phone.
- Hagane does **not** store workout history in the phone app. History lives in Garmin Connect only.

---

## 7. Tips and troubleshooting

| Problem | Fix |
| :-- | :-- |
| Routine list is empty | Open the Hagane phone app, then hold **UP** on the watch routine list |
| Edited a routine on the phone, watch is old | Open Hagane on the watch again, or hold UP on the list. A sync that arrives mid-workout is applied after the workout |
| Sync never works | Make sure Garmin Connect is running and the watch is connected; on Android disable battery optimisation for Hagane and Garmin Connect |
| Buzz / vibration missing | Check the watch's *Settings → System → Vibration* |
| Wrong rep or weight saved | Use **Undo Set**, correct reps/weight, finish the set again |

Names on the watch are plain English/ASCII text so they render cleanly on the screen.
